3. **Le moteur est derrière le marché sur ces deux lignes** : log-loss moyenne 3,169
   contre 2,986. Attendu compte tenu du gain théorique de seulement +0,0069 — deux tirages
   ne peuvent pas le mettre en évidence, et peuvent facilement l'inverser.

**Aucune de ces observations n'est exploitable à n = 2.** Elles sont écrites ici pour
être testées, pas pour être crues.

### Défaut corrigé dans `predict.py` avant le scellé

La règle du top 3 était codée en dur sur l'obstacle. La colonne affichée utilisait bien
le simulateur, mais le champ `p_top3` du JSON scellé stockait Harville/Stern et la note
de bas de tableau citait les chiffres de l'obstacle (0,5055 / 0,5077) sur une course de
trot. La règle est désormais dépendante de la discipline, et le JSON conserve les deux
valeurs sous `p_top3_stern` et `p_top3_sim` avec `p_top3_regle` pour dire laquelle fait
foi. L'enregistrement v1, produit avec le code fautif, **n'a pas été écrasé** : le
garde-fou a refusé, comme prévu. `predict.py` empile désormais les corrections en
`_v2`, `_v3`… avec le motif et un renvoi vers l'enregistrement précédent.
